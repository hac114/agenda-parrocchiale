3. REGISTRO INTENZIONI DI MESSA
---------------------------------------------------------------------
Colonne:
1. DATA CONSEGNA
2. INTENZIONI (testo libero)
3. OFFERTA (solo uso interno, NON stampata)
4. DATA APPLICAZIONE (compilata DOPO, quando la Messa è celebrata)
5. NOTE

Regole:
- Le intenzioni NON sono legate a un giorno specifico a priori.
- Si applicano "quando possibile".
- Di solito il fedele vuole sapere prima quando sarà applicata,
  quindi si tende a fissare un giorno/orario preciso in agenda.
- Numero intenzioni per Messa:
    * Feriale messa serale: 2-3
    * Altri (mattina, festivi): 1
    * Maggio: stessa gestione (2 righe bastano)
- Numerazione progressiva: NO
- Dati richiedente (nome, telefono): NO, solo l'intenzione
- Compilazione: A MANO dopo la stampa
- Righe per nome defunto accanto all'orario: 3
